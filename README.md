# Hearth & Bean — Café Website Design Demo

A single-page website design for a fictional neighborhood coffeehouse, built as a portfolio sample.

**Live look:** open `hearth-and-bean.html` directly in a browser, or enable GitHub Pages on this repo.

## What this is

A cozy, editorial-style landing page for a café — hero section, story/about, a chalkboard-style menu, hours & location, and a contact footer. Built to show what a small restaurant or café site can look and feel like: warm, unhurried, and specific to the subject rather than a generic template.

## Tech

- Plain HTML + CSS, no build step or framework
- Google Fonts (Fraunces for display, Karla for body text)
- Inline SVG illustration (no external images)
- Fully responsive, dark-mode aware, respects reduced-motion

## Notes

All content — the café name, menu, hours, and address — is placeholder, made up for this demo.
